## Подготовка

Для работы бота вам понадобятся:

1. **Telegram Bot Token** — создаётся через [@BotFather](https://t.me/BotFather)
2. **Replicate API Token** — для доступа к LLM (Claude 4.5 Sonnet)
3. **Ваш Telegram User ID** — для прав администратора бота

### Как узнать свой Telegram ID

Напишите боту [@userinfobot](https://t.me/userinfobot) — он ответит вашим числовым ID. Например: `123456789`.

Если администраторов несколько, узнайте ID каждого.

## Настройка бота в BotFather

### Шаг 1: Создание бота

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot`
3. Введите имя бота (например: `Digest Group Bot`)
4. Введите username (например: `my_digest_bot`)
5. Скопируйте токен вида `123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11`

### Шаг 2: Отключение Group Privacy Mode

**Это обязательный шаг!** Без него бот не увидит сообщения в группе.

1. В @BotFather отправьте `/mybots`
2. Выберите вашего бота
3. `Bot Settings` → `Group Privacy` → `Turn off`

Вы должны увидеть: *"Privacy mode is disabled for your_bot"*

### Шаг 3 (опционально): Настройка аватарки и описания

Бот автоматически устанавливает описание и меню команд при запуске. Аватарку можно задать вручную:

1. В @BotFather: `/setuserpic`
2. Выберите бота и отправьте картинку

## Конфигурация

### Файл .env

Скопируйте `.env.example` в `.env` и заполните:

```bash
cp .env.example .env
```

```env
# === ОБЯЗАТЕЛЬНЫЕ ===

# Токен от @BotFather
TELEGRAM_BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11

# Ваш Telegram ID (и других админов, через запятую)
ADMIN_USER_IDS=123456789,987654321

# Токен Replicate API
REPLICATE_API_TOKEN=r8_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# === ОПЦИОНАЛЬНЫЕ (есть defaults) ===

# Модель LLM
REPLICATE_MODEL=anthropic/claude-4.5-sonnet

# Расписание дайджеста
DIGEST_DAY=6                # 0=Понедельник, 6=Воскресенье
DIGEST_HOUR=20              # Час отправки
DIGEST_TIMEZONE=Europe/Moscow

# Авто-закрепление дайджеста в чате
AUTO_PIN_DIGEST=true
```

### Расписание дайджеста

По умолчанию дайджест отправляется **каждое воскресенье в 20:00** по московскому времени.

Дни недели:
| Значение | День |
|----------|------|
| 0 | Понедельник |
| 1 | Вторник |
| 2 | Среда |
| 3 | Четверг |
| 4 | Пятница |
| 5 | Суббота |
| 6 | Воскресенье |

## Добавление бота в группу

1. Откройте вашу группу в Telegram
2. Нажмите на название группы → `Добавить участника`
3. Найдите бота по username (например `@my_digest_bot`)
4. Добавьте его в группу

Бот отправит приветственное сообщение:

> 👋 Привет! Я бот для еженедельных дайджестов.
> Я буду читать сообщения в этом чате и каждую неделю формировать структурированный отчёт с ключевыми темами.

**Для автозакрепления дайджеста** бот должен быть администратором группы с правом `Pin Messages`. Если бот не админ, дайджест всё равно отправится, но не будет закреплён.

## Команды

### /digest — Генерация дайджеста

**Доступ:** только администраторы бота

Генерирует дайджест за последние 7 дней:
```
/digest
```

За произвольный период (от 1 до 365 дней):
```
/digest 14
```

При генерации бот показывает прогресс:
1. `⏳ Генерирую дайджест за 7 дней…`
2. `📨 Найдено 230 сообщений, анализирую…`
3. `✅ Дайджест отправлен!`

Если сообщений нет:
- `📭 Нет сообщений за период.`

### /status — Статистика

**Доступ:** все участники

Показывает: сколько сообщений собрано, когда был последний дайджест.

### /help — Справка

**Доступ:** все участники

Список доступных команд с описанием.

### /sources — Отслеживаемые чаты

**Доступ:** только администраторы

Показывает список всех чатов и каналов, которые бот отслеживает.

### /add_channel ID — Добавить канал

**Доступ:** только администраторы

```
/add_channel -1001234567890
```

Бот должен быть администратором канала. ID канала можно узнать через ботов вроде [@getidsbot](https://t.me/getidsbot).

### /remove_channel ID — Убрать канал

**Доступ:** только администраторы

```
/remove_channel -1001234567890
```

## Дайджест: как это работает

### Сбор данных

Бот постоянно собирает:
- Текстовые сообщения
- Подписи к фото/видео
- Цепочки реплаев (reply-to)
- Отредактированные сообщения (обновляет текст в базе)

Бот **не** собирает:
- Сообщения от других ботов
- Сервисные сообщения (вход/выход из группы)
- Стикеры, голосовые (только текст и подписи к медиа)

### Анализ

LLM (Claude 4.5 Sonnet) анализирует все сообщения и выделяет:

- **Важные темы (3-6)** — решения, договорённости, значимые новости
- **Обсуждаемые темы (3-6)** — активные дискуссии, споры, длинные треды
- **Статистика** — общее число сообщений, активных участников, самый активный

Для больших объёмов (>2000 сообщений) используется двухэтапный анализ: сначала суммаризация по дням, затем финальный дайджест.

### Формат вывода

Дайджест отправляется в формате HTML с expandable blockquotes — заголовки тем всегда видны, а описание раскрывается по тапу (на мобильных). Каждая тема содержит кликабельную ссылку на первое сообщение обсуждения.

## Inline-кнопки навигации

Под каждым дайджестом появляются кнопки:

| Кнопка | Что показывает |
|--------|----------------|
| 🔴 Важные | Только важные темы |
| 💬 Обсуждаемые | Только обсуждаемые темы |
| 📊 Статистика | Только статистика (числа, самый активный) |
| 📋 Полный | Полный дайджест (по умолчанию) |

Нажатие на кнопку заменяет текст сообщения на выбранный раздел. Текущий активный раздел выделен точками: `• 📋 Полный •`.

Кнопки работают в течение 48 часов после отправки (ограничение Telegram API).

## Работа с каналами

Бот может отслеживать Telegram-каналы в дополнение к группам.

### Подключение канала

1. Добавьте бота как **администратора** канала
2. В группе с ботом выполните: `/add_channel -1001234567890`
3. Бот начнёт сохранять посты канала

### Отключение канала

```
/remove_channel -1001234567890
```

### Особенности

- Для каналов используется отдельный промпт, фокусирующийся на контенте постов
- Дайджест каналов генерируется по тому же расписанию
- В дайджесте канала вместо "обсуждений" выделяются "тематические блоки"

## Администрирование

### Кто является администратором

Администраторы определяются переменной `ADMIN_USER_IDS` в `.env`. Это **не связано** с админами Telegram-группы — это список User ID, которым разрешено использовать привилегированные команды бота.

### Уведомления об ошибках

Если запланированный дайджест не удалось сгенерировать (ошибка API, сети и т.д.), все администраторы получат уведомление в личные сообщения:

> ⚠️ Не удалось сгенерировать дайджест для Название группы

### Логи

При запуске бот пишет логи в stdout:
```
2025-01-20 20:00:01 [INFO] bot.services.scheduler: Scheduler started: digest every Sun at 20:00 (Europe/Moscow)
2025-01-20 20:00:01 [INFO] bot.main: Bot started
```

### Резервное копирование

База данных хранится в файле `data/bot.db`. Для резервного копирования достаточно скопировать этот файл. При использовании Railway — данные привязаны к volume.

## FAQ

### Бот не видит сообщения в группе

Убедитесь, что **Group Privacy Mode выключен** в @BotFather → Bot Settings → Group Privacy → Turn off.

### Дайджест пустой / "Нет сообщений за период"

- Бот собирает только текстовые сообщения и подписи к медиа
- Проверьте, что бот был в группе в течение периода (он не может видеть сообщения, отправленные до его добавления)
- Используйте `/status` для проверки, сколько сообщений собрано

### Дайджест не закрепляется

Для автозакрепления бот должен быть **администратором группы** с правом `Pin Messages`.

### Кнопки под дайджестом не работают

Telegram позволяет редактировать сообщения только в течение 48 часов. После этого кнопки перестанут работать.

### Как изменить расписание

Измените `DIGEST_DAY` и `DIGEST_HOUR` в `.env` и перезапустите бота.

### Сколько стоит использование

- **Telegram Bot API** — бесплатно
- **Replicate API** — оплата по использованию. Один дайджест (один запрос к Claude) стоит обычно $0.01–0.05 в зависимости от объёма текста. Еженедельное использование для одной группы ~$0.20/месяц.

### Можно ли использовать в нескольких группах

Да, бот работает в нескольких группах одновременно. Добавьте его во все нужные группы — он будет собирать сообщения и генерировать дайджесты для каждой отдельно.
