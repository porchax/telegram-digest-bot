Закоммить все текущие изменения и запушь в remote. Выполни шаги последовательно.

## Шаги

### 1. Анализ изменений
- Выполни `git status` для просмотра изменённых и новых файлов
- Выполни `git diff --stat` для обзора объёма изменений
- Выполни `git log --oneline -3` для просмотра стиля предыдущих коммитов

### 2. Билд-проверка
- Выполни `npm run build` в `packages/backend` — TypeScript должен скомпилироваться без ошибок
- Выполни `npm run build` в `packages/frontend` — Vite билд должен пройти без ошибок
- Если билд падает — исправь ошибки перед коммитом

### 3. Коммит
- Добавь все изменённые и новые файлы в staging (`git add`)
- НЕ добавляй `.env`, `node_modules`, `dist/`, `*.tsbuildinfo`
- Сформируй осмысленное сообщение по conventional commits (`feat:`, `fix:`, `docs:`, `chore:`)
- Если изменения затрагивают несколько областей — используй тело коммита для деталей
- Закоммить с `Co-Authored-By: Claude Opus 4.6 <noreply@anthropic.com>`

### 4. Push
- Проверь текущую ветку и remote tracking: `git branch -vv`
- Запушь: `git push`
- Если нет upstream — `git push -u origin <branch>`
- Выведи ссылку на коммит в GitHub

### 5. Итог
Выведи краткую сводку: какие файлы были закоммичены, хеш коммита, ссылку на GitHub.
