Получи список issues из GitHub-репозитория проекта и выведи их пользователю.

## Шаги

### 1. Определи репозиторий
- Получи remote URL через `git remote -v`
- Извлеки owner/repo из URL

### 2. Получи issues
- Выполни `gh issue list --repo <owner/repo> --state open --limit 30`
- Если есть аргумент `$ARGUMENTS` — используй его как фильтр:
  - Число (например `5`) → покажи детали конкретного issue: `gh issue view <номер> --repo <owner/repo>`
  - `closed` → покажи закрытые issues: `--state closed`
  - Текст → используй как поиск: `--search "<текст>"`

### 3. Выведи результат
- Покажи таблицу с колонками: номер, приоритет (из лейблов), название
- Отсортируй по приоритету: высокий → средний → низкий
- Предложи пользователю выбрать issue для работы
